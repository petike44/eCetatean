## What This Project Is

**eCetățean** (Romanian: eCitizen) is an AI-powered civic assistant that helps Romanian citizens navigate bureaucracy. Citizens describe a life event in plain Romanian — the AI assistant named **ClaudIA** generates a step-by-step action plan, pre-filled official PDF forms, books appointments, handles digital payments, and tracks progress across all steps.

**Hackathon:** Cluj Hackathon 2026 — Digital Romania — 48 hours
**Tracks:** Your City (primary) + AI Civic Agents (special track)
**Team:** 3 university students based in Cluj-Napoca

## Database Schema (Supabase)

Tables: `profiles`, `vehicles`, `housing`, `health_info`, `education_info`, `deadlines`, `audit_log`, `civic_reports`, `civil_servant_access_log`

### Key RLS Rules
- All tables use `auth.jwt() ->> 'sub'` as user identifier (Clerk user ID)
- Citizens see only their own rows on all tables
- `audit_log`: SELECT only for citizens, INSERT only via backend (service role), NO DELETE ever, NO UPDATE ever
- Civil servant role: sees only `civic_reports` and restricted citizen view, not health/financial data
- Supabase must be configured to trust Clerk JWTs (Settings → API → JWT)

### Hash Chain (Immutable Audit Log)
Each `audit_log` entry contains:
- `data_hash = SHA256(action + actionType + timestamp + data)`
- `record_hash = SHA256(previous_record_hash + data_hash)`
- Chain starts with `GENESIS` as the first `previous_hash`
- `GET /api/audit/verify` re-validates the entire chain
- This satisfies the hackathon requirement for "blockchain or simulated distributed ledger"

## Key Product Decisions

### What eCetățean Solves
Romanian citizens lose money and time through:
1. **Unknown benefits** — parents don't claim alocație (719 RON/month, up to 12 months retroactive)
2. **Missed deadlines** — PFA freelancers miss D212 (due May 25 annually), impozit auto, ITP
3. **Bureaucratic confusion** — no single guide for life events (buying a car, moving city, having a baby)

ClaudIA's job: tell citizens what they're entitled to, when deadlines are, and generate every form pre-filled.

### Target Audiences (in order of demo priority)
1. **New parents** — highest financial impact (alocație + indemnizație = potentially 100K+ RON over 2 years)
2. **PFA freelancers** — deadline urgency (D212 May 25), common in tech community
3. **Students moving cities** — team's own experience, emotionally authentic
4. **EU car importers** — technically impressive, shows depth

### Hackathon Scoring (out of 100)
- Social Impact: 25 pts — how many people helped, how much simplified
- UX/Usability: 25 pts — smooth, accessible, fast, mobile-first
- Technical Feasibility: 20 pts — solid, realistic
- Working Demo: 20 pts — live, not just slides
- Digital Romania Coherence: 10 pts — fits the vision

### Mandatory Checklist Items (must all be present)
- ✅ Login + 2FA — Clerk with email OTP (ROeID simulation)
- ✅ Immutable data — hash chain in `audit_log` table
- ✅ Access control — citizen / civil_servant / system tiers via Clerk roles + Supabase RLS
- ✅ Accessibility — ARIA labels, semantic HTML, WCAG AA contrast, keyboard nav
- ✅ Works on phone + tablet + desktop — mobile-first, Vercel deployed
- ✅ Live link — Vercel deployment URL

## The Three Demo Scenarios

### Demo 1 — New Parent (30 seconds, opens the pitch)
User says: *"Tocmai mi s-a născut copilul."*
ClaudIA shows: amount of unclaimed alocație in RON, 24-month indemnizație estimate, pre-filled benefit application PDF, deadline countdown.
Key number visible: the total RON the parent has not yet claimed.

### Demo 2 — PFA Freelancer (45 seconds)
User says: *"Am PFA, am nevoie de D212."*
ClaudIA shows: deadline alert (May 25), calculated CAS + CASS amounts, pre-filled D212 PDF ready to download.
Key moment: correct RON amounts auto-calculated from profile data.

### Demo 3 — Car from Germany (60 seconds, shows technical depth)
User says: *"Am cumpărat o mașină din Germania."*
ClaudIA opens the 7-step Life Event Dashboard. Each step shows: office, cost, action button (book RAR, pay ghișeu.ro, get RCA, book DRPCIV). Document wallet shows pre-filled DRPCIV cerere, impozit auto declaration, ANAF TVA certificate request.
Key moment: all 7 steps orchestrated from one screen, cost total visible, zero Googling needed.
