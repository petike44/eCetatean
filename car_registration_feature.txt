WHAT YOU ARE BUILDING
=====================
A complete end-to-end car registration flow inside the eCetățean app.
The user should be able to start and finish the entire registration
process without ever opening Google. Every step that can be completed
online is handled inside the app. Every step that requires a physical
visit is made into one single prepared visit — the app generates all
documents, books the appointment, and tells the user exactly what to
bring.

Two flows must be supported:
  A) Domestic purchase (car bought in Romania) — 4 steps
  B) EU/Germany import (car brought from Germany or another EU state) — 7 steps

The user's entry point is the ClaudIA chat screen. They type something
like "am cumpărat o mașină din Germania" and ClaudIA asks two
clarifying questions, creates a life event record, and opens the
Life Event Registration Dashboard for that specific process.

STEP-BY-STEP ANALYSIS: WHAT IS ONLINE VS PHYSICAL
===================================================

FLOW A — DOMESTIC PURCHASE (car bought in Romania from another person)

  STEP 1: Notarize sale contract
    Status: PHYSICAL (notary office, cannot be skipped)
    App does:
      - Generate pre-filled Contract de vânzare-cumpărare PDF
        (seller name/CNP left blank — user fills at notary)
        (buyer fields: full name, CNP, address from profile — pre-filled)
        (vehicle fields: from profile if car already added, or user inputs)
      - Show notary offices in Cluj with address and phone
      - Estimated cost: 150–300 RON
      - Action button: "Găsește notar" → link to harta notarilor publici

  STEP 2: Transcription at DRPCIV
    Status: PHYSICAL (mandatory counter visit) + ONLINE BOOKING
    App does:
      - Generate pre-filled Cerere tip DRPCIV (transcription request)
      - Open DRPCIV booking: https://www.drpciv.ro/drpciv-booking/activities/21
        in an in-app webview component (or deep link on mobile)
      - Show complete document checklist for this visit
      - Estimated time at counter: 30–45 minutes when file is complete
      - Action buttons: "Rezervă programare DRPCIV" + "Descarcă cerere completată"

  STEP 3: Declare for impozit auto at Primărie
    Status: PARTIALLY ONLINE (ghișeu.ro for some primării + some accept email)
    App does:
      - Generate pre-filled Declarație impozit auto PDF
      - Link to Primăria Cluj online portal for tax declaration
      - Direct link: https://www.ghiseul.ro (for participating primării)
      - Fallback: show Primăria Cluj address and Tax window hours
      - Action buttons: "Declară online ghișeu.ro" + "Descarcă declarație"

  STEP 4: Get RCA insurance
    Status: FULLY ONLINE (can be done entirely in app)
    App does:
      - Open RCA comparison inside in-app webview
      - Link: https://www.ieftine.ro/asigurari/rca (neutral aggregator)
      - After purchase, user uploads confirmation to document wallet
      - Action button: "Compară și cumpără RCA"


FLOW B — EU/GERMANY IMPORT (car brought from Germany or EU)

  STEP 1: Translate German documents
    Status: ONLINE AVAILABLE (authorized online translators in Romania)
    App does:
      - Explain what needs to be translated:
          Brief mare (Teil II / Fahrzeugbrief) + purchase invoice/Kaufvertrag
      - Link to online authorized translation services:
          https://www.traduceri.ro or https://traductori.ro (example providers)
      - Show that both documents need stamps from authorized translator
      - Estimated cost: 150–300 RON, same-day delivery common
      - Action button: "Găsește traducător autorizat online"

  STEP 2: RAR Omologare + ITP + CIV
    Status: PHYSICAL (mandatory, car must be present) + ONLINE BOOKING
    App does:
      - Open RAR booking system: https://www.rar.ro/web/en/homologare
      - Explain the 3 things RAR does in one visit:
          CIV (Cartea de identitate a vehiculului) — 250 RON
          ITP (Inspecție tehnică periodică) — 250 RON
          Certificat de autenticitate — 250 RON
          Total: 750 RON (more if car manufactured after Aug 2018 and no CoC)
      - Check: does user have CoC (Certificate of Conformity)?
          If car manufactured after Aug 2018 and no CoC: add 500 RON for RAR to issue it
      - Note: if car has no valid export plates (Zollkennzeichen),
          cannot be driven to RAR — must get red plates (numere roșii) from DRPCIV first
      - Action buttons: "Rezervă programare RAR" + "Verifică dacă ai nevoie de CoC"

  STEP 3: Get TVA Certificate from ANAF
    Status: PARTIALLY ONLINE (SPV digital submission possible)
    App does:
      - Generate pre-filled Cerere certificat TVA ANAF
      - Explain: for SH car bought from private person in Germany,
          TVA is almost certainly 0, but certificate is still required
      - Two paths:
          Path A (has SPV account): submit via Spațiul Privat Virtual
            Link: https://www.anaf.ro/anaf/internet/RO/spv
          Path B (no SPV): physical visit to ANAF Cluj
            Address: Str. Mihail Kogălniceanu 10, Cluj-Napoca
            Hours: Luni–Vineri 08:30–16:30
      - Action buttons: "Depune prin SPV" + "Descarcă cerere pentru ghișeu"

  STEP 4: Register at Primărie — REMTII stamp + impozit auto
    Status: PARTIALLY ONLINE
    App does:
      - Explain: the translated+notarized purchase contract needs
          the REMTII registration number before DRPCIV will accept it
      - Generate Declarație impozit auto PDF (pre-filled)
      - Link to Primăria Cluj portal for online declaration
      - Note: for EU imports this step must happen AFTER translation
          because the REMTII stamp goes on the translated contract
      - Action buttons: "Declară online" + "Descarcă declarație"

  STEP 5: Pay DRPCIV fees via ghișeu.ro
    Status: FULLY ONLINE (mandatory before counter visit)
    App does:
      - Direct link to ghișeu.ro payment for registration certificate (49 RON)
        URL: https://www.ghiseul.ro/ghiseul/public/taxe/taxe-speciale
        Service: "Certificate de înmatriculare"
      - Separate payment for license plates (~200 RON)
      - After payment, user saves receipt in document wallet
      - Action button: "Plătește 49 RON pe ghișeu.ro" and "Plătește plăcuțe"

  STEP 6: Get RCA insurance (in new Romanian owner's name)
    Status: FULLY ONLINE
    Same as Flow A Step 4.

  STEP 7: DRPCIV final appointment + document submission
    Status: PHYSICAL (mandatory counter visit) + ONLINE BOOKING
    App does:
      - Generate pre-filled Cerere tip DRPCIV
      - Open DRPCIV booking: https://www.drpciv.ro/drpciv-booking/activities/21
      - Show complete document checklist for final DRPCIV visit:
          Cerere tip (generated by app)
          Buletin original + copie
          Contract vânzare-cumpărare autentificat + tradus cu REMTII stamp
          CIV original (from RAR)
          ITP valid (from RAR)
          RCA valid (new Romanian policy)
          Certificat de autenticitate (from RAR)
          Certificat TVA ANAF
          Dovada plată certificat înmatriculare (49 RON from ghișeu.ro)
          Dovada plată plăcuțe (~200 RON)
      - Action buttons: "Rezervă programare DRPCIV" + "Descarcă cerere completată"

4. ADD NEW API ROUTES TO /backend/src/routes/

   Create a new file: /backend/src/routes/life-events.ts

   This route manages the persistent life event progress tracker.

   Endpoints:

   POST /api/life-events
     Body: { event_type: string, event_data: object }
     Auth: requireAuth
     Action:
       - Look up the procedure from knowledge base using event_type
       - Insert a new row in life_event_progress with:
           user_id, event_type, event_title (from procedure), event_data,
           steps_status (object with keys "step_1" through "step_N" all set to "pending"),
           total_steps (length of steps array),
           current_step: 1
       - Write audit entry: "Eveniment civic pornit: [event_title]"
       - Return the created record including all step details from knowledge base
     Response: { success: true, data: { id, event_type, steps, step_details_from_kb } }

   GET /api/life-events
     Auth: requireAuth
     Action: return all life events for user, ordered by started_at DESC
     Include step_details merged from knowledge base for each event
     Response: { success: true, data: [ ...events ] }

   GET /api/life-events/:id
     Auth: requireAuth
     Action: return single life event with full step details from knowledge base
     Verify user_id matches before returning
     Response: { success: true, data: { ...event, step_details: [...from kb] } }

   PATCH /api/life-events/:id/steps/:stepNumber
     Body: { status: 'pending' | 'in_progress' | 'completed' | 'skipped' }
     Auth: requireAuth
     Action:
       - Verify ownership
       - Update steps_status JSONB: set steps_status["step_N"] = status
       - If status is 'completed', advance current_step to next pending step
       - If all steps completed, set is_completed = true, completed_at = now()
       - Update updated_at = now()
       - Write audit entry: "Pas [N] completat: [step_title] ([event_title])"
     Response: { success: true, data: updated event }

   Register this route in /backend/src/index.ts:
     import { lifeEventsRoute } from './routes/life-events'
     app.route('/api/life-events', lifeEventsRoute)
